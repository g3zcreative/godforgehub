

## Problem

Google Search Console rejects the sitemap because `public/sitemap.xml` and `robots.txt` reference URLs on the Supabase domain (`yawfmtkrnewpdxjdypmc.supabase.co`). GSC requires sitemaps to be hosted on the same domain they describe.

Since Lovable serves a static SPA, there's no server-side rendering to dynamically serve XML from `godforgehub.com/sitemap.xml`. The `public/` folder is the only way to serve files from the domain.

## Solution

Generate a **complete flat sitemap** directly in `public/sitemap.xml` containing all ~1,250 URLs. Additionally, create an admin "Regenerate Sitemap" feature so you can keep it updated as content changes.

### 1. Generate `public/sitemap.xml` as a complete flat file

Query all tables (heroes: 205, skills: 810, imprints: 166, mechanics: 105, weapons: 51, armor_sets: 25, bosses: 2, news: 11, guides: 2, plus ~9 static pages) and write a single `<urlset>` file with every URL. This is well within the 50,000 URL sitemap limit.

### 2. Update `public/robots.txt`

Change the Sitemap directive from the Supabase function URL to:
```
Sitemap: https://godforgehub.com/sitemap.xml
```

### 3. Modify the edge function to output a flat sitemap

Update `supabase/functions/sitemap/index.ts` to generate a single flat `<urlset>` (no sitemap index, no `?type=` params). This makes it easy to regenerate the static file.

### 4. Add admin "Regenerate Sitemap" button

Add a button in the admin panel that:
- Calls the sitemap edge function
- Displays the generated XML
- Provides a "Copy to clipboard" action

When content changes significantly, you click the button, copy the XML, and ask me to update `public/sitemap.xml` — or you can just ask me to regenerate it anytime.

### Technical details

**`public/sitemap.xml`** — Complete flat file with all URLs, generated by querying all DB tables. Format:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://godforgehub.com/</loc><priority>1.0</priority></url>
  <url><loc>https://godforgehub.com/database/heroes/hel</loc><priority>0.7</priority></url>
  <!-- ... all URLs ... -->
</urlset>
```

**Edge function** — Simplified to return a single flat sitemap (all categories combined), making regeneration a single call.

**Admin panel** — New "Regenerate Sitemap" section (likely in AdminSettings or AdminSeo) with a button to fetch and display the latest sitemap XML.

### Files changed
- `public/sitemap.xml` — Regenerated with all ~1,250 URLs
- `public/robots.txt` — Point to `godforgehub.com/sitemap.xml`
- `supabase/functions/sitemap/index.ts` — Simplified to flat output
- Admin page (likely `AdminSeo.tsx` or `AdminSettings.tsx`) — Add regenerate button
